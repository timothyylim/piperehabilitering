# Pipe Reviews

Arrakis workload that syncs Google Place reviews into the static
Piperehabilitering site.

Source of truth: `~/repos/piperehabilitering/ops/pipe-reviews/`.

Deploy:

```bash
cd ~/repos/piperehabilitering/ops/pipe-reviews
./deploy.sh
```

Secrets stay local and on Arrakis:

- `.env` in this directory: `GOOGLE_PLACES_API_KEY`, `PIPE_REHAB_PLACE_ID`
- `~/.secrets/arrakis/github_pipe_rehab`: deploy key used by the container to
  push review updates back to `timothyylim/piperehabilitering`

Runtime:

- Remote path: `/home/tim/pipe-reviews`
- Container: `pipe-reviews`
- Schedule: `crontab`, Europe/Oslo
- Logs: `ssh arrakis "docker logs pipe-reviews --tail 80"` or
  `/home/tim/pipe-reviews/data/run.log`

## Cached sync (2026-10-21)

Dedicated Cloud project: `pipe-rehab-reviews-20261021`, owned by
`tim@hyperspeed.studio`. Places API (New) enabled. Server key restricted to
`places.googleapis.com` and Arrakis outbound IP `168.144.107.250`.
The key stays in ignored `.env` configuration, never in Git or public HTML.

The Docker `/data` bind mount persists `reviews-cache/place.json` and
`reviews-cache/fetch-state.json` across container recreation. A valid cached
response is reused for 24 hours. Each network attempt, including a failed one,
is recorded before fetching and starts a 24-hour cooldown. A hard application
limit allows at most 40 attempts per UTC calendar month. Corrupt quota state
fails closed. Do not delete this state or add retries that bypass the guards.
This is an application limit, not a Google Cloud billing quota.

A file lock prevents overlapping complete sync jobs; a separate fetch lock
protects the cache. Errors leave the previously published HTML intact.
Visitors never call Google: the website serves static HTML generated by the
scheduled job. All 13 review sections reuse the same cached response.

The 24-hour TTL can defer a daily cron run if its preceding fetch finished less
than 24 hours earlier. No force-refresh flag is provided intentionally.

Recovery verified 2026-10-21: the new restricted integration returned rating 5.0
and 16 total reviews. The job updated all 13 pages and pushed them to main;
the public homepage showed 16 reviews. A second full sync reported a cache hit,
changed no files, and left the October API-attempt counter at 1. Eight tests
passed (HTTP errors/redaction, successful fetch, cache reuse/expiry, failure
cooldown, monthly cap, and corrupt state). The former Google permission failure
is resolved by the dedicated project; its original underlying account setting
was not established.
